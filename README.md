# Job Application Tracker

A React-based web application that helps users explore job listings, manage job applications, and track their application status through a responsive dashboard.

## Features

- **Login and Role-Based Access** – Different access for admin and user roles.
- **Job Management** – Add, view, edit, and delete job listings.
- **Job Details** – View detailed information about available jobs.
- **Job Applications** – Apply for jobs and manage submitted applications.
- **Application Status Tracking** – Track statuses such as Applied, Under Review, Interview, Selected, and Rejected.
- **Dashboard** – View job and application information in one place.
- **Search Jobs** – Search job listings using keywords.
- **Duplicate Application Prevention** – Prevent applying to the same job more than once.
- **Withdraw Applications** – Withdraw submitted applications.
- **Local Storage** – Persist application and job data in the browser.
- **Responsive UI** – Designed to work across different screen sizes.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Browser Local Storage

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/thatiparthivenkatesh1722/job-application-tracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd job-application-tracker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Data Storage

This project uses browser Local Storage to persist job listings and application data. Data is stored locally in the browser and is not shared between different browsers or devices.
